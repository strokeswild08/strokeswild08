**How to try the work:** Play/Open/Demo links run in a browser. Fieldpack and Nightshift are native projects: download the ZIP, import `project.godot` in Godot 4.4.1 and press F5. Each project links to its source and setup guide.

The Godot kits passed headless integration checks; graphical playthroughs and exported builds are still pending. They use procedural starter visuals.
